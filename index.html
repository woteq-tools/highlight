    How it works

    1. Pick a language — 190+ grammars are bundled, so it works offline too.
    2. Type or paste your code; the highlighted preview refreshes on every keystroke.
    3. Choose a theme, switch line numbers on, then copy the result as plain code, HTML or Markdown.

    The page reads ?language=, ?theme= and ?numbers=1 from the URL and keeps them in sync as you change things — bookmark a combination you like.

    Frequently asked questions

    Is my code uploaded anywhere?

    No. Highlighting happens in your browser with Highlight.js, and the tool makes no network requests at all — the library, the grammars and the themes are all bundled with the page.

    Which HTML should I paste into my blog?

    Use the HTML tab. It produces a <pre> block where every token carries its own inline colour, so it looks the same no matter what theme (or no theme) the surrounding site applies. The Highlighted tab is a live preview only, and the Markdown tab emits a fenced block for Markdown-based sites.

    Why does a language not appear in the list?

    The catalogue comes straight from Highlight.js, so it covers every grammar that project ships. A couple of very new or exotic grammars may be missing from a given release — check the Highlight.js language list for the full, up-to-date set.

    Can I use this offline?

    Yes. Once the page has loaded, everything it needs is already on your machine. You can even install it as an app from your browser's menu.
